# ADR-0007: 지도는 카카오맵 JS SDK를 쓴다

- **상태**: 승인됨
- **날짜**: 2026-08-22
- **결정자**: 팀 전원

## 맥락 (Context)

관리자 대시보드는 건물 단위 위험 히트맵 + 가구 상태 색상 지도가 핵심이다(FR-6, F5). 방문 큐의 출동 경로 제시(FR-7, Should)도 지도 위에서 이뤄진다. PRD §8이 지도·경로 출처로 카카오맵 API를 지정했다. 대상 주소는 전부 한국이다.

## 결정 (Decision)

**카카오맵 JavaScript SDK**로 지도·마커·오버레이를 구현한다. 주소→좌표 변환은 카카오 로컬(geocoding) API, 출동 경로(FR-7)는 카카오모빌리티 길찾기 API를 사용한다. SDK 앱 키는 `NEXT_PUBLIC_KAKAO_MAP_KEY`, REST 키는 서버 전용 env로 관리한다.

## 근거 (Rationale)

- 한국 주소 체계(지번/도로명)와 건물 표현 품질이 국내 최상
- 무료 쿼터로 데모 충분, 팀 친숙도 높음
- PRD가 명시한 출처와 일치

## 검토한 대안 (Alternatives)

- **네이버 지도** — 동급이나 PRD 명시와 다르고 이점 없음. 기각
- **Leaflet + OSM** — 키 불필요 장점은 있으나 국내 건물·주소 표현이 약해 "히트맵의 설득력"이 떨어짐. 기각
- **Google Maps** — 국내 지도 데이터 제약. 기각

## 결과 (Consequences)

- 긍정: 국내 데모 품질, 경로 API까지 한 생태계
- 부정/트레이드오프: SDK가 전역 스크립트 방식이라 React 래핑 필요(react-kakao-maps-sdk 사용 가능 — 도입 시 이 ADR 범위 내로 본다). 키 발급/도메인 등록 선행 작업 필요
- 되돌리기: 지도 컴포넌트를 한 곳(`src/components/map/`)에 격리해 교체 비용 최소화
