# ADR-0011: 데모는 로컬 실행 기본, 트리거는 수동 시뮬레이션으로 한다

- **상태**: 승인됨
- **날짜**: 2026-08-22
- **결정자**: 팀 전원

## 맥락 (Context)

데모는 5분짜리 라이브 시연이다(PRD §10). 행사장 네트워크·클라우드 장애는 통제 불가능한 리스크다. 또한 F1의 "매일 17시 기상청 폴링"은 데모 시점에 실제 폭염이 아닐 수 있어 그대로는 시연이 안 된다. DB는 SQLite 파일이라([ADR-0004](0004-sqlite-prisma.md)) 서버리스 배포와 궁합이 나쁘다.

## 결정 (Decision)

- **데모는 발표 노트북의 로컬 실행(`npm run dev` 또는 `npm run build && npm start`)을 기본**으로 한다. 담당자 폰 화면은 같은 Wi-Fi의 로컬 IP로 접속하거나 노트북의 반응형 화면으로 시연
- 기상 트리거는 실제 API 연동을 구현하되, 데모용으로 **관리자 화면의 수동 시뮬레이션 버튼**("8/21 비상 발령")으로 임의 날짜·단계를 발령할 수 있게 한다 — PRD §10 시나리오 2번이 요구하는 연출
- 심사용 공개 URL이 필요해지면 Vercel + Postgres(Neon) 전환을 D2에 판단 (provider 교체는 [ADR-0004](0004-sqlite-prisma.md) 참조)

## 근거 (Rationale)

- 로컬 실행은 데모 리스크(네트워크·콜드스타트·쿼터)를 0으로 만듦
- 수동 트리거는 편법이 아니라 데모 시나리오의 명시적 요구("8/21 비상 발령" 연출)이며, 판정 로직 자체는 실제 코드 경로를 태움

## 검토한 대안 (Alternatives)

- **Vercel 우선 배포** — SQLite 파일이 서버리스에서 유실됨, DB 교체 작업 선행 필요. 데모 필수 요건이 아니므로 기각(스트레치로 보류)
- **VM/Fly.io 배포** — 인프라 작업이 48h 예산 초과. 기각
- **실시간 기상 데이터에만 의존** — 데모 날짜에 폭염이 없으면 시연 불가. 기각

## 결과 (Consequences)

- 긍정: 데모 안정성 최대화, 시나리오 연출 자유
- 부정/트레이드오프: 심사위원이 각자 접속해보는 경험은 제공 못 함 — 필요 시 D2 오후에 Vercel 전환 판단
- 되돌리기: 해당 없음 (배포 추가는 언제든 가능)
