# 담당자 지도 탭 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 비활성인 담당자 하단 `지도` 탭을 `/map`으로 연결하고, 담당 가구를 건물 단위 위험도와 가구 상태로 확인한 뒤 기존 대상자 상세 화면으로 이동할 수 있게 한다.

**Architecture:** 서버 컴포넌트인 `/map`이 기존 `getBoard()`를 직접 호출하고, 순수 함수 `toMapBuildings()`가 같은 건물의 대상자를 하나의 지도 포인트로 묶는다. 클라이언트 컴포넌트는 추가 패키지 없이 `next/script`로 카카오맵 JavaScript SDK를 로드해 `Circle` 오버레이를 그리고, 선택된 건물의 대상자·상태·위험 사유는 React HTML 패널로 표시한다.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript strict, Tailwind CSS 4, Kakao Maps JavaScript SDK, Vitest

**Spec:** `docs/PRD.md` F3·F5, FR-6, §8·§9; `docs/architecture.md` §6·§7·§8; `docs/adr/0007-kakao-map.md`; `docs/adr/0014-figma-design-with-domain-terms.md`

## Global Constraints

- 지도 탭의 사용자는 담당자(생활지원사)이며 구현 경로는 `/map`이다. 관리자 `/admin` 대시보드는 별도 범위다.
- `src/lib/domain.ts`의 `RiskGrade`, `HouseholdStatus`, `GRADE_LABEL`, `HOUSEHOLD_STATUS_LABEL`만 사용하고 상태 문자열을 하드코딩하지 않는다.
- 위험 사유는 스코어링 엔진이 저장한 `reasons`를 수정·요약하지 않고 그대로 표시한다.
- 비경보일에는 경보·등급·상태가 있는 것처럼 표현하지 않는다. 지도 조회 때문에 `AlertDay`나 알림을 만들지 않는다.
- 클라이언트에는 `NEXT_PUBLIC_KAKAO_MAP_KEY`만 전달한다. `KAKAO_REST_KEY`, 전화번호, 메모는 지도 payload에 포함하지 않는다.
- Prisma 스키마·마이그레이션과 새 Route Handler는 추가하지 않는다. 서버 페이지가 `getBoard()`를 직접 재사용한다.
- 새 npm 패키지를 추가하지 않는다. SDK 타입은 사용하는 표면만 로컬로 선언한다.
- 지도 포인트는 건물별로 하나다. 경보일의 건물 색은 그 건물 대상자 중 가장 높은 위험 등급(숫자가 가장 작은 등급)을 따른다.
- 카카오 SDK 실패·키 누락·표시할 건물 없음 상태를 빈 화면으로 두지 않는다.
- 구현 시작 전 `npm install` 후 `node_modules/next/dist/docs/`의 현재 Next.js 16 `Script`·Client Component 가이드를 읽는다.

## 범위에서 제외

- **채택 — 기존 `getBoard()` 재사용:** 현재 경보일 결과에 좌표·등급·상태·사유가 모두 있어 중복 DB 조회와 API를 만들 필요가 없다. 비경보일 결과에 같은 건물 필드만 올리면 된다.

- [ ] **Step 4: 최소 건물 집계 함수 구현**

`src/lib/map/data.ts`는 DB를 조회하지 않고 전달받은 `Board`만 변환한다. 건물 등급은 가장 작은 등급 숫자, 점수는 최댓값을 사용한다.

```ts
import type { Board, BoardSubject, RosterSubject } from "../board/today";
import type { HouseholdStatus, RiskGrade } from "../domain";

export interface MapHousehold {
  subjectId: string;
  name: string;
  age: number;
  grade: RiskGrade | null;
  score: number | null;
  status: HouseholdStatus | null;
  statusLabel: string | null;
  open: boolean;
  reasons: string[];
}

export interface MapBuilding {
  buildingId: string;
  address: string;
  roadAddress: string | null;
  lat: number;
  lng: number;
  grade: RiskGrade | null;
  score: number | null;
  households: MapHousehold[];
}

function isBoardSubject(subject: RosterSubject | BoardSubject): subject is BoardSubject {
  return "grade" in subject;
}

export function toMapBuildings(board: Board): MapBuilding[] {
  const subjects: Array<RosterSubject | BoardSubject> = board.alerted
    ? board.groups.flatMap((group) => group.subjects)
    : board.subjects;
  const byBuilding = new Map<string, MapBuilding>();

  for (const subject of subjects) {
    const alerted = isBoardSubject(subject);
    const building = byBuilding.get(subject.buildingId) ?? {
      buildingId: subject.buildingId,
      address: subject.address,
      roadAddress: subject.roadAddress,
      lat: subject.lat,
      lng: subject.lng,
      grade: null,
      score: null,
      households: [],
    };

    building.households.push({
      subjectId: subject.subjectId,
      name: subject.name,
      age: subject.age,
      grade: alerted ? subject.grade : null,
      score: alerted ? subject.score : null,
      status: alerted ? subject.status : null,
      statusLabel: alerted ? subject.statusLabel : null,
      open: alerted ? subject.open : false,
      reasons: alerted ? subject.reasons : [],
    });

    if (alerted) {
      building.grade =
        building.grade === null || subject.grade < building.grade
          ? subject.grade
          : building.grade;
      building.score = Math.max(building.score ?? Number.NEGATIVE_INFINITY, subject.score);
    }
    byBuilding.set(subject.buildingId, building);
  }

  return [...byBuilding.values()];
}
```

`useEffect`에서 지도를 만든 뒤 모든 좌표를 `LatLngBounds.extend()`하고, 건물이 둘 이상이면 `map.setBounds(bounds)`, 하나면 `map.setLevel(3)`을 호출한다. 이 동작은 카카오 공식 `Map`, `LatLngBounds` API만 사용한다.

```tsx
const containerRef = useRef<HTMLDivElement>(null);

useEffect(() => {
  const maps = window.kakao?.maps;
  const container = containerRef.current;
  if (!ready || !maps || !container || buildings.length === 0) return;

  const first = new maps.LatLng(buildings[0].lat, buildings[0].lng);
  const map = new maps.Map(container, { center: first, level: 3 });
  const bounds = new maps.LatLngBounds();
  const circles: Array<{
    circle: KakaoCircle;
    handler: () => void;
  }> = [];

  for (const building of buildings) {
    const center = new maps.LatLng(building.lat, building.lng);
    bounds.extend(center);
    const handler = () => setSelectedBuildingId(building.buildingId);
    const circle = new maps.Circle({
      map,
      center,
      radius: 35,
      strokeWeight: 3,
      strokeColor: building.grade ? fillByGrade[building.grade] : neutral,
      strokeOpacity: 1,
      fillColor: building.grade ? fillByGrade[building.grade] : neutral,
      fillOpacity: 0.55,
      clickable: true,
    });
    maps.event.addListener(circle, "click", handler);
    circles.push({ circle, handler });
  }

  if (buildings.length > 1) map.setBounds(bounds);
  else map.setLevel(3);

  return () => {
    for (const { circle, handler } of circles) {
      maps.event.removeListener(circle, "click", handler);
      circle.setMap(null);
    }
  };
}, [buildings, ready]);
```

- [ ] **Step 4: 등급별 건물 원과 클릭 선택 구현**

SDK가 직접 쓰는 색은 기존 CSS 토큰을 읽어 사용한다.

```ts
const css = getComputedStyle(document.documentElement);
const fillByGrade = {
  [RiskGrade.CRITICAL]: css.getPropertyValue("--color-danger").trim(),
  [RiskGrade.HIGH]: css.getPropertyValue("--color-warn").trim(),
  [RiskGrade.MODERATE]: css.getPropertyValue("--color-calm").trim(),
};
const neutral = css.getPropertyValue("--color-slate").trim();
```

이 값들은 위 `useEffect` 안에서 `bounds` 생성 직후 읽어 hook dependency를 늘리지 않는다.

```tsx
import { notFound } from "next/navigation";
import { BottomNav } from "@/components/today/BottomNav";
import { KakaoMap } from "@/components/map/KakaoMap";
import { isIsoDate } from "@/lib/board/format";
import { getBoard } from "@/lib/board/today";
import { toMapBuildings } from "@/lib/map/data";

export const dynamic = "force-dynamic";

export default async function MapPage(props: PageProps<"/map">) {
  const params = await props.searchParams;
  let date: string | undefined;
  if (params.date !== undefined) {
    if (!isIsoDate(params.date)) notFound();
    date = params.date;
  }
  const workerId = typeof params.workerId === "string" ? params.workerId : undefined;
  const board = await getBoard({ date, workerId });
  const buildings = toMapBuildings(board);

  return (
    <>
      <main className="mx-auto flex w-full max-w-[520px] flex-1 flex-col gap-5 bg-surface px-5 pt-11 pb-[100px]">
        <header>
          <h1 className="text-2xl font-bold text-ink">담당 가구 지도</h1>
          <p className="text-base text-ink-soft">
            {board.dateLabel}{board.dong ? ` · ${board.dong}` : ""}
          </p>
        </header>
        <KakaoMap
          apiKey={process.env.NEXT_PUBLIC_KAKAO_MAP_KEY}
          buildings={buildings}
          date={board.date}
          workerId={workerId}
        />
      </main>
      <BottomNav current="map" date={date} workerId={workerId} />
    </>
  );
}
```

- [ ] **Step 2: 하단 탭이 날짜·담당자 문맥을 보존하도록 최소 수정**

const ITEMS = [
  { key: "today", label: "오늘", href: "/today", Icon: HomeIcon },

  { key: "log", label: "기록", href: null, Icon: ListIcon },

```ts
function withContext(path: string, date?: string, workerId?: string): string {
  const query = new URLSearchParams();
  if (date) query.set("date", date);
  if (workerId) query.set("workerId", workerId);
  const value = query.toString();
  return value ? `${path}?${value}` : path;
}
```

`href`가 있는 항목은 `withContext(href, date, workerId)`를 사용한다. `src/app/today/page.tsx`의 마지막 호출은 명시적으로 선택된 검색 문맥을 넘긴다.
